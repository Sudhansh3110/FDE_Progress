# Capstone: Full FDE Engagement

**Days 41–45** · topics: disc, comm, prod, intv

## Brief
Simulate a complete customer engagement end to end, reusing your earlier builds, as if you were the FDE for a real company.

## Requirements
- [ ] Pick a realistic customer (e.g., a mid-size Indian bank's support team) and write a one-page deployment brief
- [ ] Discovery notes from a mock interview with a friend playing the customer; stakeholder map
- [ ] Pilot scope doc: metric + baseline, in/out of scope, milestones, dependencies, risks, acceptance criteria
- [ ] Working solution combining at least two earlier projects, deployed
- [ ] Eval results against the acceptance criteria
- [ ] Production-readiness checklist with non-negotiables, rollout plan with rollback triggers
- [ ] 10-minute demo (recorded) with an honest limits section
- [ ] Handover pack: runbook, weekly status update example, value report with ROI estimate

## Stretch goals
- Blameless postmortem for a simulated incident
- Playbook: how to repeat this for the next customer
- Present it as a mock take-home walkthrough to a friend or mentor

## Deliverable
A single portfolio page linking every artifact: this is what you show in FDE interviews.

## Daily log
Add one line per day you work on this, oldest at the bottom is fine too — just be honest.

- YYYY-MM-DD: what you built today, what you struggled with
